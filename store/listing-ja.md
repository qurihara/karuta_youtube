
## 詳細説明 (Description) — 最大 16,000 文字

```
YouTubeで競技かるたの試合動画を視聴中、ブラウザ内のVAD (Voice Activity Detection) で読み手の発話を検出し、HUDの「静粛まで巻き戻し」ボタンをワンクリックするだけで次の上の句が始まる直前まで動画を巻き戻して再生し直します。

■ 競技かるた向けの「特殊な巻き戻し」

通常の巻き戻しは「○秒前に戻す」ですが、競技かるたの「上の句が始まった瞬間」は札を取るための最重要ポイントで、人間がそこに正確に巻き戻すのは至難です。本拡張は音声認識で
読みのリズム (下の句末尾→沈黙→次の上の句冒頭) を検出し、「次の上の句が始まった時刻 − N秒」に正確にseekします。

■ 主な機能

・YouTube通常動画 (/watch?v=...) と YouTube Live (/live/...) の両方に対応
・動画上部中央にコンパクトなHUDを表示 (「静粛まで巻き戻し」ボタンと⚙のみ)
・⚙をクリックすると詳細設定 (N秒の調整、無音閾値の調整、検出区間のタイムライン、リアルタイム診断) が展開
・新たな上の句の開始が検出されるとボタンがフラッシュアニメーションで点滅
・ツールバーアイコンからワンタップで拡張全体をON/OFF
・ライブ配信時はDVRバッファ範囲を超える巻き戻しは自動でグレー化

■ 動作の仕組み

・YouTubeの<video>要素から AudioContext と MediaElementAudioSourceNode で音声を取得
・AudioWorkletで16kHzにリサンプル
・Silero VAD (WebAssembly) でリアルタイムに音声区間/無音区間を判定
・「直前の無音区間が一定以上 (既定0.5秒) で、次に音声が始まる瞬間」を上の句開始候補としてマーク
・ユーザーが巻き戻しボタンを押した時、その候補時刻のN秒前 (既定1秒) に動画をseek

■ プライバシー

・音声データを外部に送信することは一切ありません
・全ての処理はあなたのブラウザ内のWebAssemblyで完結します
・ユーザー設定はchrome.storage.sync (あなた自身のGoogleアカウント内同期) にのみ保存
・分析ツール・トラッキング・広告SDKは一切含みません
・プライバシーポリシー: https://github.com/qurihara/karuta_youtube/blob/main/PRIVACY.md

■ ソースコード (オープンソース)

https://github.com/qurihara/karuta_youtube

■ 同梱モデル

・Silero VAD ONNX (MIT License) — https://github.com/snakers4/silero-vad
・onnxruntime-web (MIT License)

■ 制限事項

・音量が極端に小さい動画では検出精度が落ちることがあります (最大32×の自動ゲインで補正していますが超えるとモデルが反応しません)
・DRM保護コンテンツ (一部のYouTube Premium映画など) は音声取得不可
・広告再生中の発話も検出対象に含まれます
```
