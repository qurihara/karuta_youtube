# Chrome Web Store — 権限正当化文 (Permissions Justification)

ストア審査ではマニフェスト中の各権限について「なぜ必要か」を入力する必要があります。下記をそのまま貼り付け可能。

---

## storage 権限の正当化

```
ユーザーの設定値 (拡張全体のON/OFF、巻き戻し秒数N、無音閾値、HUD表示パラメータ) をchrome.storage.syncに保存します。ユーザー個別の好みを記憶するためのみに使用し、外部送信は一切行いません。
```

## host_permissions (https://www.youtube.com/*) の正当化

```
本拡張はYouTubeの動画ページにHUDをオーバーレイ表示し、<video>要素から音声を取得して音声区間検出を行うため、YouTubeドメインへのアクセスが必要です。YouTube以外のサイトには一切影響しません。
```

## remote code

```
本拡張は外部サーバーからコードを動的に読み込みません。Silero VADのONNXモデルとonnxruntime-webのWebAssemblyを含む全ての実行コードは、拡張パッケージ (zip) 内に同梱されています。
```

## データ取り扱い (Data usage)

ストアの「データ使用の開示」フォームで申告する内容:

| データ種別 | 収集する? | 用途 |
|---|---|---|
| 個人を特定できる情報 (PII) | いいえ | — |
| 健康情報 | いいえ | — |
| 金融情報 | いいえ | — |
| 認証情報 | いいえ | — |
| 個人通信 | いいえ | — |
| 位置情報 | いいえ | — |
| ウェブ閲覧履歴 | いいえ | — |
| ユーザーアクティビティ | いいえ | — |
| ウェブサイトコンテンツ (= 音声波形) | **はい (一時的)** | 用途: 音声区間検出のためにブラウザ内でのみリアルタイム処理。保存も外部送信もしない |

ウェブサイトコンテンツの追加質問:
- 暗号化送信? → 該当なし (送信していない)
- ユーザーは無効化可能? → はい (拡張のポップアップでON/OFF切替可)

宣誓事項 (3 つすべてに「はい」):
- ✅ 上記の用途以外には使用しません
- ✅ 上記の用途以外で第三者に販売・譲渡しません
- ✅ 信用調査や個人特定のために使用しません
